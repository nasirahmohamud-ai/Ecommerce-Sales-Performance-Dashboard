# E-Commerce Sales Performance Dashboard

## Project Overview
This project analyzes e-commerce sales data using SQL and Power BI to uncover business insights related to revenue, customer behavior, product performance, and sales trends.

The goal of this project was to practice:
- SQL data analysis
- Business-focused querying
- Power BI dashboard development
- Data visualization and storytelling

---

## Tools Used
- MySQL
- Power BI
- CSV Dataset
- SQL Queries
- Data Visualization

---

## Dataset Features
The dataset includes:
- Order ID
- Customer ID
- Product
- Quantity
- Unit Price
- Total Price
- Payment Method
- Order Status
- Referral Source
- Coupon Codes
- Shipping Address
- Tracking Number

---

## SQL Analysis Performed

### Business Questions Answered
- Which products generated the highest revenue?
- Which payment methods generated the most sales?
- Which referral sources brought the most revenue?
- Which customers generated the highest revenue?
- What is the average order value?
- Which order statuses appear most frequently?
- Which products performed best among delivered orders?
- Do customers using coupon codes generate more revenue,
  than those without coupons?

### SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- Aliasing

## Key Insights
- Certain products contributed significantly more revenue than others.
- Referral platforms like Instagram and Email generated strong sales performance.
- Revenue trends fluctuated throughout the year with noticeable peak months.
- Customer purchasing behavior varied across payment methods.
